Data and limitations

This exhibit uses simulated visits generated for the Neural Network Explorer exercise. The network takes the hour, weekday, staff count, and queue size and predicts a wait in minutes.

Evaluation covers only a held-out sample of this synthetic dataset. The estimates are for classroom exploration. The data lacks visit complexity and service duration, which could affect waits in real clinics.
